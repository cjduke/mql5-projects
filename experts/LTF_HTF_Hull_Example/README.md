LTF_HTF_Hull_PropRules (the Prop Trader EA)

Multi-timeframe mean-reversion EA using an LTF → HTF approach. H1 HMA200 sets the directional anchor, H4 HMA20/HMA50 confirms structure, D1 HMA8 sets the higher-timeframe colour filter, and H1 RSI(3) times the entry. Each timeframe sets a persistent flag that remains valid until its own condition breaks; the EA only trades when all four flags agree on direction. Stop = 3× H1 ATR, target = 1:1. Includes a full prop-firm risk layer: profit-target kill switch, maximum total drawdown limit, optional daily drawdown limit, minimum valid trading days counter, and per-day CSV logging of every event. Requires the UnifiedHullMA indicator.(Note: This is for educational purposes only, it is itended as a deployable strategy for the live market)
